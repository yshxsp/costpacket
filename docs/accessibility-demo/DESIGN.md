# Demonstration design

Subject: a small workshop's request for a materials quote. This is a fictional,
controlled fixture, not a client site. Keep the same product and layout before
and after so the fixes can be reviewed without a redesign distracting from them.

Palette: workshop blue #153957, action blue #174fa3, paper #f6f8fc,
text #172b3a, supporting text #455d74, borders #c9d5e5.
Type: system sans serif, 16px body, 34px heading, tabular prices.
Layout: left-aligned order form beside a compact materials summary; one column
on a phone. The quote dialog is the only overlay. No entrance animation.

Review: avoid the cream/serif/monospace defaults used elsewhere in CostPacket.
This fixture needs clear form hierarchy and interaction feedback. The illustration
explains the selected material; it is not decorative marketing artwork.
