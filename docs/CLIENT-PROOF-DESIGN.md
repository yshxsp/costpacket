UI fix. Job: inspect one example, try the corrected form, and read the evidence
without signing up or downloading a repository. This is a portfolio page, not a
checkout or a claim of paid client work.

muted #4a6075, rule #cad5e2. Reuse the self-hosted IBM Plex Sans. Use Fraunces
only in the existing product, not as a default editorial heading here.

Layout: left-aligned short explanation beside the actual before/after submit
control diff; two side-by-side screenshot crops below; source, report and live
fixture links adjacent to the evidence. On mobile, stack in reading order.

cards. A code change and its keyboard behavior are the important information.
